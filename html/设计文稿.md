# 曼谷各国风咖啡甜品地图 · 设计文稿（V2 · 主题沉浸版）

> 升级目标：从「列表式换色」升级为「沉浸式主题展览」——每个国家风格是一套**完整的视觉语言**（字体 / 纹理 / 母题 / 布局 / 动效 / 留白哲学），读者滚动时像在八家不同国家的小店里穿行。

---

## 〇、设计总纲

- **统一骨架 + 八套皮肤**：全局导航 / 进度条 / 灯箱交互保持一致；章节内部完全换肤。
- **每主题一套设计语言**：配色、字体、装饰母题（SVG）、布局气质、微动效、图廊风格，全部随 `data-theme` 切换。
- **可落地、可分享**：纯 HTML/CSS/JS，图片 base64 内嵌，单文件自包含；字体用系统字体栈（离线可用）。

---

## 一、全局系统（交互骨架，保持统一）

- 吸顶胶囊导航（8 风格 + 开篇），当前主题高亮并采用该主题色。
- 顶部细进度条随当前主题色平滑过渡。
- 图廊 9:16 竖图，点击 lightbox 放大（Esc / 点击关闭）。
- 响应式：移动端单列、桌面多列；平滑滚动。
- 字体策略：每主题在 CSS 变量里指定 `--font-head` / `--font-body`。

---

## 二、八套主题皮肤（核心）

每套给出：概念 / 配色 / 字体 / 母题 / 布局气质 / 图廊。

### 🇯🇵 日式 · 侘寂留白（wabi-sabi）
- 概念：和室、障子、和紙、間（ma）。安静、克制、自然材质。
- 配色：生成り #F7F3EC / 木肌 #EFE7D8 / 墨 #2B2622 / 淡墨 #7A6F5E / 線 #E2D7C4 / 朱 #C0392B（印鑑·鸟居）。
- 字体：标题 衬线宋体（Songti / Yu Mincho 风），**竖排标题**（writing-mode）；正文 黑体。
- 母题：円相（enso 手绘圆 SVG）、朱印（方形印章写店名）、障子格纹分隔。
- 布局：不对称留白，标题竖排靠一侧，大量负空间；卡片如一张和紙便笺（纸纹背景）。
- 图廊：白细边框 + 纸影，hover 微抬。

### 🇫🇷 法式 · 宫廷优雅
- 概念：奶油、金线、画框、甜点如艺术。
- 配色：奶油 #FBF6EA / 浅金 #C9A227 / 深金 #A8841C / 墨 #3A3220 / 線 #E8DDBB / 勃艮第 #7B2D3A。
- 字体：标题 优雅衬线（Didot/Georgia 风，字距略宽）；正文 衬线。
- 母题：双线描边画框、卷草角花（SVG）、细金分隔线。
- 布局：对称居中，卡片如一张 carte 菜单卡，带画框阴影。
- 图廊：金线画框，hover 浮起带金影。

### 🇩🇰 北欧 · 极简克制
- 概念：斯堪的纳维亚、daylight、功能主义。
- 配色：冷白 #F4F6F8 / 石板 #6B7A8F / 深板岩 #2C3640 / 雾蓝 #9AA7B4 / 線 #D8E0E7。
- 字体：无衬线（Helvetica 风），字距宽松，小标全大写。
- 母题：细直线条网格、几何圆点，留白即装饰。
- 布局：强网格、左对齐、大量留白，层级靠字号。
- 图廊：无边框，仅靠间距与灰度统一。

### 🇰🇷 韩式 · 粉彩公主
- 概念：Pinterest、干花、奶油白、空气感。
- 配色：奶油白 #FDF6F8 / 柔粉 #D98BA0 / 莓粉 #E9A7BC / 奶茶 #F3E2DD / 墨 #4A3340 / 線 #F0D9E2。
- 字体：圆润无衬线，字距宽松可爱。
- 母题：干花 / 小爱心点缀、大圆角、柔光。
- 布局：圆角卡片、居中、轻盈。
- 图廊：大圆角 + 柔粉描边，hover 弹性放大。

### 🇮🇹 意式 · 实验室极简
- 概念：提拉米苏实验室、白调、讲究。
- 配色：暖白 #F4F8F2 / 罗勒绿 #2E7D32 / 陶土 #B5651D / 墨 #26331F / 線 #D7E8D3。
- 字体：无衬线 + 意大利手写体点缀（cursive）作招牌字。
- 母题：极简；小方砖（italian tile）底纹。
- 布局：干净网格，招牌字手写体放大。
- 图廊：白边 + 绿影。

### 🇦🇺 澳式 · 早午餐明快
- 概念：砖房、藤椅、海风、明亮。
- 配色：米白 #FDF6EF / 赤陶 #E07A3F / 沙滩 #F2D9BE / 海蓝 #4A90A4 / 墨 #3F2A1C / 線 #F0D9C6。
- 字体：无衬线、字距宽松、活泼。
- 母题：藤编纹理、太阳 / 波浪线条。
- 布局：明快分区、色块。
- 图廊：暖橙描边。

### 🇹🇷 中东 · 古铜神秘
- 概念：125 年古建、铜壶沙煮、拱门、几何。
- 配色：**深暖底 #241B14** / 古铜 #8E5A3C / 金 #C9A227 / 沙 #EFE0D4 / 浅字 #E8DCCB。
- 字体：衬线（带东方感），标题更装饰。
- 母题：马蹄拱（SVG arch）、八角星几何纹、铜壶剪影。
- 布局：深色背景 + 金色拱门卡片，神秘高级。
- 图廊：拱形遮罩（上大下小圆角）或金边。

### 🇹🇭 泰式 · 热带艺术
- 概念：彩窗、古木、斑兰绿、金。
- 配色：孔雀绿 #2A9D8F / 金 #D4A017 / 奶油 #FBF7EE / 墨 #1F3A36 / 線 #C8E8E1。
- 字体：无衬线 + 泰式花体点缀。
- 母题：kranok（泰式卷草）纹、彩窗分割、热带叶。
- 布局：撞色分区，活泼。
- 图廊：绿金描边。

## 三、单店卡片 schema（保持不变，且每主题适配）
店名 · 国旗 · 口碑标签(✅⚠️🆕) · 一句话博主点评 · 出片点 · 招牌推荐 · 位置/交通 · 价位 · 营业时间 · 实拍图廊（旗舰 3 张；加映有图则带图，无图则文字卡）。

## 四、技术实现要点
- 每个 `<section data-theme="jp|fr|...">` 通过 CSS 变量整套管肤。
- 母题用内联 SVG / CSS 背景实现，零外部资源。
- `IntersectionObserver` 切换 `--active` 控制进度条/导航；章节自身用 `data-theme` 局部变量完成换肤。
- 日式竖排用 `writing-mode: vertical-rl`。
- 图片 base64 内嵌（自包含）；加映图按可用数量嵌入。
