# 曼谷「各国风」咖啡甜品地图 · HTML 设计文稿

> 设计者视角：一份**攻略博主**出品的图文地图——不是冷冰冰的餐厅列表，而是「按美学风格逛曼谷咖啡」的随身攻略。
> 语气：亲切、有观点、实用（告诉你哪家园子最好拍、几点去人少、点什么不踩雷）。
> 本版范围：8 家旗舰实拍店（恰好覆盖 8 种国家/风格各一家），每章附 2–3 家同风格文字「加映」。

---

## 一、阅读动线（信息架构）

1. **封面 Hero**
   - 主标题「曼谷各国风咖啡甜品地图」+ 副标题（按美学风格，挑一家对味的店）
   - 数据徽章：8 国风 · 8 家实拍 · 出片向
   - 向下滚动提示
2. **博主开场白**
   - 为什么做这份地图（拍照好看 + 不同国家风格）
   - 怎么用（按风格挑 / 按区域排 / 图例说明 ✅⚠️🆕）
3. **主题快速导航（吸顶）**
   - 8 个风格胶囊，一键直达；滚动时当前风格高亮，整页气质随之切换
4. **8 个主题章节（核心）**
   - 每章一套**独立视觉皮肤**，对应一家旗舰实拍店 + 该风格「同场加映」文字小卡
5. **页脚**
   - 图片来源声明（小红书用户笔记，仅供风格参考）+ 全 40 家清单待解锁提示

---

## 二、主题皮肤系统（切到不同主题，样式要相匹配）

每个 `<section data-theme>` 自带局部 CSS 变量；吸顶导航 + 顶部细进度条随当前章节**平滑过渡**为该主题色（IntersectionObserver 驱动）。即「切到不同主题推荐咖啡店时，整页视觉语言随之变化」。

## 三、单店卡片信息 schema（要全）

- 店名 · 国旗 · 口碑标签（✅ 多源真实好评 / ⚠️ 偏网红打卡 / 🆕 新晋）
- **一句话点评**（博主观点，带人味）
- **风格定位 / 出片点**（为什么好拍、怎么拍）
- **招牌推荐**（推荐菜 / 必点）
- **位置 & 交通**（片区 + 最近 BTS/地标 + 顺路动线标注）
- **价位**（人均/单品）
- **营业时间**
- **实拍图廊**（3 张/行，9:16 竖图，点击放大）

---

## 四、交互 & 技术方案

- **单文件 HTML**，图片以 base64 内嵌（方便分享，不丢图、不依赖图床）
- 吸顶胶囊导航 + 滚动高亮当前主题（IntersectionObserver）
- 顶部细进度条随主题色过渡
- 图片 `loading=lazy` + 点击 lightbox 放大
- 响应式：移动端单列、桌面多列；平滑滚动 + 主题色过渡动画
- 页脚图片来源声明（小红书），合规且体面
