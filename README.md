# 曼谷各国风咖啡甜品地图 · Bangkok Cafe Guide

> 一份「按美学风格逛曼谷咖啡」的图文攻略——攻略博主视角，拍照好看，也真好喝。

## 项目简介

本项目把一份曼谷咖啡甜品店候选清单，做成了一份**主题化、可分享的单文件 HTML 攻略**。
按国家 / 美学风格（日 · 法 · 北欧 · 韩 · 意 · 澳 · 中东 · 泰）分组，
每家店给出 **出片点、招牌推荐、位置交通、价位、营业时间**，并配小红书实拍图。

不是冷冰冰的餐厅列表，而是一份随身攻略：告诉你哪家园子最好拍、几点去人少、点什么不踩雷。

## ✨ 亮点

- **8 套主题皮肤**：每个风格一套独立配色与视觉语言；滚动切换到不同主题时，吸顶导航与顶部进度条会随主题色**平滑过渡**，整页气质随之变化。
- **单文件自包含**：图片以 base64 内嵌，一个 `.html` 走天下，分享不丢图、不依赖图床。
- **实拍图来自小红书**：经 `agent-reach / opencli` 抓取真实探店笔记图，统一裁成 9:16 竖图，3 张一行。
- **完整数据底座**：`scripts/cafes_data.json` 结构化收录 40 家店，可平滑扩展出完整版。

## 🛠 技术栈

- 纯 **HTML + CSS + 原生 JS**，无框架、无构建步骤，单文件可直接打开。
- 主题切换：用 `IntersectionObserver` 监听当前章节，动态更新 CSS 变量（`--accent` 等）。
- 图片灯箱：原生 JS 点击放大（支持 Esc / 点击关闭）。
- 图片来源：小红书（通过 `agent-reach` 的 OpenCLI 频道 `opencli xiaohongshu search/download` 抓取）。

## 🚀 本地重新生成

```bash
# 依赖：Python 3 + Pillow
pip install pillow

# 重新生成自包含 HTML（读取 scripts/cafes_data.json + html_assets/ 下的图）
python scripts/build_html_final.py
# 输出：html/曼谷各国风咖啡甜品地图.html
```

> 如需替换某家店的实拍图，把对应 9:16 图放到 `html_assets/<shop_key>/` 下（01/02/03.jpg），再跑上面的命令即可。

## 📊 数据

- `scripts/cafes_data.json`：40 家店，字段含 `name / flag / cat（风格）/ sig（招牌）/ loc（位置价位）/ tag（口碑）/ sample（是否样张）`。
- 本版 HTML 精选 **8 家旗舰实拍**（每风格一家）+ 每章 2–3 家同风格「加映」文字卡。
